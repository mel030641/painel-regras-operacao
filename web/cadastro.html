Cadastro de atos complementares

Preencha os dados do ato, ou leia-os de um PDF, confira a prévia e envie o pedido pelo GitHub. O pedido vira um PR validado automaticamente e só entra no painel depois do merge. Quem não usa o GitHub pode copiar ou baixar o registro e enviá-lo à equipe.

1. Ler dados de um PDF (opcional)

O arquivo é lido só no seu navegador: não é enviado nem gravado no repositório, que é público. A leitura depende do PDF ter texto; PDF digitalizado (imagem) não é lido. Os campos preenchidos pela leitura ficam destacados e devem ser conferidos.

“Enviar pelo GitHub” abre um pedido (issue) já preenchido no repositório; é preciso estar conectado ao GitHub com permissão no repositório. A automação valida o registro e abre um PR, que alguém da equipe revisa e aprova. Atos com informação restrita não devem ser cadastrados, porque o repositório é público.
